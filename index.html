Core modules

一个入口，五类媒体

每个模块都围绕真实使用链路设计：导入源、搜索、播放或阅读、保留进度。

视频

CMS 多源与 Bilibili 源、跨源搜索、HLS / FLV / MP4 播放、历史进度与收藏。

  • 跨源搜索
  • 广告切片过滤
  • 下载与缓存

音乐

榜单、歌单、歌手与专辑浏览，支持本地播放记录与歌词展示。

  • 榜单
  • 歌单
  • 歌词

小说

规则书源导入、书架、阅读历史与书签，支持 TXT / EPUB / HTML 导出。

  • 规则书源
  • 断点阅读
  • 导出

漫画

分类、排行、搜索、书架与章节阅读器，桌面端支持滚动与翻页两种模式。

  • 章节进度
  • 离线缓存
  • 阅读模式

直播

IPTV M3U 订阅、频道分组、XMLTV 节目单与 EPG 当前节目定位。

  • M3U
  • EPG
  • 频道分组
Four platforms

一份代码，四端同形

粒子从应用图标开始，在四端形态之间流动。移动端、Windows、macOS 与 Android TV 共享同一套业务层与适配器，端差异只留在传输、文件系统与界面能力上。

点击标签切换形态 · 鼠标掠过可拨动粒子
